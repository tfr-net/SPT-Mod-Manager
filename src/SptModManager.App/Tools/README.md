# Bundled tools

`7zr.exe` is the official 7-Zip Reduced Standalone Console (version 26.03, x86) by Igor Pavlov, downloaded unmodified
from https://github.com/ip7z/7zip/releases/tag/26.03. It is public domain. SHA-256:
`ad4c82fadcbdf93c03b4fc440f300509c7d60c5c2f4d183e35d9d70d6957037d`

It is embedded in the Windows build and only used to unpack .7z mod archives and SPT releases when no installed
7-Zip is found. See THIRD-PARTY-NOTICES.md at the repository root.
